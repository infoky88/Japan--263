Japan Travel Money Calculator — Installable PWA

Default exchange rate: RM26.30 per ¥1,000.

To install as an Android app, host all files in this folder on an HTTPS website. Then open the site in Chrome and tap the in-app “Install on Home Screen” button or Chrome menu > Install app / Add to Home screen.

The app works offline after the first successful visit. Entries are stored locally in the browser/app on that device.
